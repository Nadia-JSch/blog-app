This is a small CSS playground for hover states.

What I want from it:

- layered borders
- soft shadows instead of loud ones
- slight movement instead of big jumps
- links and cards that feel alive without becoming annoying

## What I’m looking for

The question is how much visual feedback is useful before it starts to feel overdesigned.

1. Cards that lift by `1px` or `2px` instead of bouncing.
2. A glow that only appears on hover and focus.
3. Border colors that shift before the background does.
4. Buttons that feel tactile without looking glossy.

## Notes

The hard part is restraint.

Most UI starts looking worse the second every element tries to ask for attention at the same time. The experiment is not really about adding more motion. It is about finding out what the smallest useful amount of motion is.
